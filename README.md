# Абай мұрасының 7 әлемі

«Абай мұрасы – заманауи білім беру үдерісінде» облыстық педагогикалық хакатонына арналған цифрлық білім беру ресурсы. Абай Құнанбаев атындағы мектеп-гимназиясы.

Сайт: https://refleymeng-cyber.github.io/abai/

Сайт бір `index.html` файлынан тұрады. 3D бөлімдер мен қаріптер интернеттен жүктеледі.
